# Research: 방명록 (021)

`가안`은 추천대로 정한 것(2026-10-20 사용자 "끝까지 다 해"). 바꾸고 싶으면 그 줄만 고친다.

| ID | 정할 것 | 고른 것 | 다른 선택지 | 이유 |
|---|---|---|---|---|
| D-1 | 모듈 | 새 모듈 `guestbook`(블로그 위, 글과 나란히). 블로그 주인은 `BlogDirectory`로 묻는다. 소식은 이벤트 `GuestbookWrittenEvent`·`GuestbookRepliedEvent`, 구독 모듈이 커밋 뒤 듣는다 `가안` | 블로그 모듈 안 | 블로그 모듈을 키우지 않고 모듈 규칙(아래는 위를 모름)을 지킨다 |
| D-2 | 누가 쓰나 | 로그인한 회원만, 주인은 답장만 `가안` | 손님 이름+비밀번호 | 계정 없는 글은 스팸을 막기 어렵다. 회원 정지(022)가 그대로 듣는다 |
| D-3 | 답장 | 엽서 줄의 칸(`reply`, `replied_at`), 한 개 `가안` | 댓글처럼 여러 개 | 방명록은 주고받는 한 쌍이면 충분하다. 표 하나로 끝난다 |
| D-4 | 너무 잦은 글 | 회원마다 30초 간격 + 한 블로그 하루 3장, 회원 잠금(pg_advisory_xact_lock)으로 한 줄 세우기 `가안` | Redis | 댓글(005 D-2)과 같은 방법 |
| D-5 | 우표 | 다섯 가지 이름(`pine`·`wave`·`moon`·`plum`·`crane`)을 CHECK로, 그림은 화면의 SVG `가안` | 사진 우표 | 원고지·우편 콘셉트, 저장 공간 없음 |
| D-6 | 소식 | `notification.kind`에 `guestbook`(주인: 새 엽서), `gb_reply`(쓴 사람: 답장) `가안` | 소식 없음 | 우편함이 있으니 방명록이 살아난다 |
| D-7 | 모양 | 엽서 격자(넓으면 3줄), 엽서마다 기울기 조금, 꽂힐 때 떨어지며 소인이 찍힘, 봉한 엽서는 밀랍 봉인, 답장은 엽서를 뒤집어 본다 `가안` | 목록 | 다른 블로그 서비스와 다르게 |
