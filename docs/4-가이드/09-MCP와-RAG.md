# 09. MCP와 RAG (AI 비서 연결)

> 2026-10-20 사용자: "남들과 다른 기능, MCP나 RAG도 좋다". 명세는 [`specs/020`](../../specs/020-mcp-connect/spec.md), 코드 0.15.0.

## 한 줄 요약

**내가 쓰는 AI(Claude 등)에게 글결 "열람증"을 건네면, AI가 내 블로그에서 맞는 단락을 찾아 출처와 함께 답한다.** 찾는 일은 글결 서버가, 답을 쓰는 일은 내 AI가 한다. 그래서 글결 서버에는 돈이 드는 AI 열쇠가 필요 없다.

## 낱말 세 개

| 낱말 | 쉬운 뜻 | 우리 서비스에서는 |
|---|---|---|
| **MCP** (Model Context Protocol) | AI 앱과 바깥 서비스가 말을 주고받는 **공통 규칙**. USB처럼 규칙만 맞으면 어느 AI 앱이든 꽂아 쓸 수 있다 | `POST /api/v1/mcp` 한 주소. Claude Code, Claude Desktop 등이 붙는다 |
| **도구** (tool) | MCP 서버가 AI에게 "이런 일을 해 줄 수 있어요"라고 내놓는 기능 | 글 찾기, 단락 찾기, 글 읽기, 내 글 목록, 내 블로그 통계, 초안 남기기 |
| **RAG** (검색 증강 생성) | AI가 답하기 전에 **자료를 먼저 찾아 읽고**, 그 자료를 근거로 답하는 방법. 지어내는 답이 줄고 출처를 댈 수 있다 | 글결은 앞의 "찾기"(R)를 맡고, 뒤의 "답 쓰기"(G)는 사용자의 AI가 한다 |

## 비유: 도서관 사서와 열람증

| 우리 것 | 도서관으로 치면 |
|---|---|
| 글결 서버 | 도서관. 책(원고)이 단락까지 정리되어 있다 |
| 개인 열쇠 (`gk_…`) | 내 이름으로 낸 **열람증**. 기한이 있고, 잃어버리면 정지하고 새로 낸다 |
| 내 AI 비서 | 내 심부름을 하는 **사서**. 열람증을 들고 도서관에 와서 책을 찾아 읽고, 나에게 요약해 준다 |
| 단락 찾기 | 사서가 책 전체가 아니라 **맞는 쪽만 복사해 오는 것**. 몇 번째 단락인지, 어느 책인지(주소)를 같이 적어 온다 |
| 초안 남기기 | 사서가 내 책상에 **메모를 두고 가는 것**. 책장(발행)에 꽂는 건 내가 한다 |

## 어떻게 찾나 (단락 찾기)

1. 볼 수 있는 글 중에서 검색어가 들어 있는 글을 최근 순으로 50개까지 고른다. 남의 비공개 글은 처음부터 고르지 않는다.
2. 글을 **단락**으로 나눈다. 빈 줄이 단락의 경계. 코드 블록은 통째로 한 단락, 사진만 있는 줄은 뺀다. "## 제목" 한 줄만 있는 덩어리는 다음 단락 앞에 붙인다(제목만 가져오면 인용할 내용이 없으므로).
3. 단락마다 점수를 매긴다: 검색어 낱말이 몇 번 나오나(세 번까지만 센다, 같은 말을 도배해도 이기지 못하게) × 그 낱말이 얼마나 **드문가**(여러 글에 흔한 말은 점수가 낮다). 제목에 낱말이 있으면 덤을 조금 준다.
4. 점수 높은 순으로 글마다 2개, 모두 8개까지. 600자가 넘는 단락은 맞은 곳 둘레만 잘라 온다.
5. 결과에는 글 제목, 블로그 이름, **주소**, 몇 번째 단락인지가 붙는다. AI는 이것을 출처로 달아 답한다.

이 방법은 "낱말 맞추기"라 뜻이 비슷한 다른 말은 못 찾는다. 대신 돈과 서버 메모리가 들지 않고, 결과를 사람이 따라가 확인할 수 있다. 뜻으로 찾는 임베딩은 [비슷한 글](../../specs/014-ai-writing/spec.md)에서 쓰는 Ollama가 서버에 켜지면 나중에 더할 수 있다.

## 안전장치

- **열쇠 원문은 저장하지 않는다.** 서버에는 SHA-256(되돌릴 수 없는 지문)과 앞 8글자만 남는다. 그래서 만들 때 한 번만 보여 준다.
- 열쇠는 **MCP 주소에서만** 통한다. 열쇠로는 글 쓰기·지우기 같은 다른 API를 부를 수 없고, 세션 쿠키도 생기지 않는다.
- 할 수 있는 일을 고른다: **읽기만** 또는 **읽기 + 초안**. 초안 열쇠도 발행은 못 한다.
- 열쇠마다 1분에 60번까지. 다른 사이트의 웹 페이지가 몰래 부르는 요청(Origin이 다름)은 막는다.
- 끊으면 바로 막히고, 탈퇴하면 열쇠도 지워진다.

## 써 보기 (Claude Code)

```bash
claude mcp add --transport http geulgyeol https://geulgyeol.java21.net/api/v1/mcp \
  --header "Authorization: Bearer <마이페이지에서 만든 열쇠>"
```

그다음 Claude에게 "글결에서 내가 쓴 제주 여행 글을 찾아 맛집 이야기만 출처와 함께 정리해 줘"처럼 물어본다. Claude Desktop 설정은 마이페이지 화면의 "붙이는 법" 탭에 열쇠를 채워 보여 준다.

## Claude 앱 커넥터로 붙이기 (0.17.0)

열쇠를 복사해 붙이는 방법은 Claude Code처럼 설정 파일을 만질 수 있는 앱에서만 됩니다. Claude 앱(웹·데스크톱·모바일)의 **커스텀 커넥터**에는 열쇠 칸이 없어서, 대신 **OAuth**라는 약속으로 붙습니다.

비유로 보면, 열쇠 방식은 **열람증을 직접 만들어 건네는 것**이고, OAuth는 **사서 데스크에서 위임장에 도장을 찍어 주는 것**입니다.

1. Claude 앱의 설정 → 커넥터 → 커스텀 커넥터 추가에 글결 MCP 주소(마이페이지 **AI 비서 연결**의 "Claude 앱(커넥터)" 탭에서 복사)를 넣습니다.
2. Claude가 글결에 "누구신가요?"를 묻고(메타데이터), 스스로 이름을 적어 등록합니다(동적 등록).
3. 내 브라우저에 글결 **위임장**이 열립니다. 누가(Claude)·누구의(내 글결)·무엇을(읽기만 / 초안까지)·언제까지가 원고지 칸에 적혀 있고, 허락하면 붉은 인장이 찍힙니다.
4. Claude는 위임장 번호(허락 코드)를 1시간짜리 **출입증**과 30일짜리 **갱신 표**로 바꿉니다. 출입증이 지나면 갱신 표로 새 출입증을 받고, 그때마다 갱신 표도 새것으로 바뀝니다.

안전장치:

- 허락 코드는 5분 동안 한 번만 쓸 수 있습니다. 누가 같은 코드를 또 쓰면 그 연결을 끊습니다.
- 이미 바뀐 옛 갱신 표가 다시 오면(누가 훔쳐 쓴 것으로 보고) 연결을 끊습니다.
- 글결에는 출입증·갱신 표의 원문이 남지 않습니다(SHA-256 지문만).
- 마이페이지 **연결된 앱**에서 언제든 끊을 수 있고, 비밀번호를 바꾸거나 이용이 정지되면 모두 끊깁니다.

이 흐름은 공식 MCP SDK 클라이언트로 처음부터 끝까지 확인했습니다(`specs/023` T007).
