# 첫 업데이트 글 초안 (T014)

배포 뒤 관리자로 로그인해 `/notices/new`에서 아래처럼 올린다. CHANGELOG `[0.6.0]`을 쓰는 사람 말로 옮긴 것이다.

| 칸 | 값 |
|---|---|
| 종류 | 업데이트 |
| 릴리스 번호 | `0.6.0` |
| 제목 | 공지사항이 생겼어요 |
| 고정 | 켜기 (다음 업데이트 글이 올라오면 끈다) |

## 본문

```markdown
글결에 **공지사항**이 생겼습니다. 앞으로 서비스가 바뀌면 여기에 먼저 알려 드릴게요.

## 이번에 바뀐 것

- 머리글의 **공지**를 누르면 업데이트 소식과 공지를 한곳에서 볼 수 있어요.
- 마지막으로 본 뒤 새 글이 올라오면 **공지** 옆에 작은 점이 생겨요. 목록을 한 번 보면 사라집니다.
- **업데이트** 탭에는 서비스가 바뀐 소식이, **공지** 탭에는 점검 같은 안내가 올라와요.

## 보이지 않는 곳에서

- 개발자를 위한 API 설명서를 정리했어요.
- 화면이 제대로 동작하는지 자동으로 확인하는 테스트를 더했어요. 같은 문제가 다시 생기지 않도록 지키는 장치예요.

늘 글결을 써 주셔서 고맙습니다.
```
