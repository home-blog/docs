# Research: 편집실 (018)

`가안`은 추천대로 정한 것(2026-10-19 사용자 "알아서, 색다르게"). 바꾸고 싶으면 그 줄만 고친다.

| ID | 정할 것 | 고른 것 | 다른 선택지 | 이유 |
|---|---|---|---|---|
| D-1 | 모듈 | 새 모듈 `editorial`(맨 위, 통계처럼). 신고는 `community`·`board`의 맨 위 틀로 묻고 닫고, 글 잠금은 글 모듈의 틀 `PostModeration`으로 한다. 내림 소식은 이벤트 `PostTakenDownEvent`·`BoardPostRemovedEvent`로 내고 구독 모듈이 커밋 뒤 듣는다 `가안` | 각 모듈에 관리자 API를 흩어 둠 | 관리자 일을 한곳에 모으고, 아래 모듈은 편집실을 모른다 |
| D-2 | 내림의 뜻 | 글을 **비공개로 돌리고 잠금**(`post.locked_at`, `post.lock_reason`). 지우지 않는다 `가안` | 지우기, 별도 숨김 상태 | 숨김 상태를 따로 두면 목록·검색·피드·RSS 쿼리를 모두 고쳐야 한다. 비공개는 이미 모든 곳에서 빠진다. 주인은 글을 잃지 않는다 |
| D-3 | 신고 상태 | `post_report`에 `resolved_at`, `resolution`(`taken_down`·`dismissed`) 칸. 대기 = `resolved_at IS NULL` `가안` | 처리 표 따로 | 신고 줄마다 언제 어떻게 닫혔는지가 남는다 |
| D-4 | 처리 기록 | 새 표 `editorial_action`(대상 종류 post·board, 대상 번호(지워지면 비움), 그때의 제목, 처리 `taken_down`·`dismissed`·`removed`·`unlocked`, 사유, 관리자, 시각) `가안` | 신고 줄만 | 글마당 글은 지우면 신고도 사라지므로 따로 남긴다 |
| D-5 | 글마당 신고 | 새 표 `board_report`(블로그 글 신고와 같은 칸, UNIQUE(회원, 글), 글을 지우면 CASCADE) `가안` | `post_report`에 섞기 | 대상 표가 다르다(FK) |
| D-6 | 현황 숫자 | 요청마다 `count(*)` 여섯 번(관리자 몇 명만 본다) `가안` | 캐시 | 단순하고 늘 맞다 |
| D-7 | 모양 | 탭 `검토 대기 · 글마당 · 처리 기록`, 처리 단추는 붉은 "내림"·먹색 "반려" 도장, 내린 글 주인에게는 우편함 우표 "편집실" `가안` | 일반 관리자 표 | 원고지·도장 콘셉트 |
