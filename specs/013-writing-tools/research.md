## 구현 방식 (가안)

- Flyway V12: `post_draft`, `series`, `series_post`, `post_image.post_draft_id`. ERD는 `ERD-변경-요청.md` E-10.
- 설정 `writing.*`(임시 저장 개수·자동 저장 간격·예약 최대 일수·확인 간격·잔디 시간대), `series.*`.
- 예약 확인 작업은 `writing.schedule.check-interval`(1분)마다 돈다. 한 번에 최대 50개를 집는다.
- 임시 저장을 발행·예약 발행할 때는 지금의 글쓰기 서비스(`PostWriteService`)를 그대로 부른다: 검사, 태그, 이미지 연결, 요청 번호가 모두 같은 길을 탄다.
- 분류 지우기 검사(`CategoryPostCounter`)는 예약된 임시 저장 글도 센다(S4-6). 예약이 없는 임시 저장 글의 분류는 `ON DELETE SET NULL`.
- 블로그가 닫힐 때(탈퇴) 임시 저장 글과 연재도 지운다.
- 화면: 글쓰기 화면에 "임시 저장" 버튼·자동 저장 표시·"예약" 시각 고르기·연재 고르기, 글 관리에 "임시 저장" 칸, 블로그 관리에 "연재" 메뉴, 블로그 화면에 잔디와 연재 목록, 글 읽기에 연재 표시.
- 테스트 먼저(테스트 전략): 각 사용자 이야기의 받아들이는 기준(S1-1 ~ S4-6)을 테스트 이름으로. 시각 경계(지금, 1분 뒤, 30일, 30일 1분)와 날짜 경계(한국 0시 10분, 365일째)는 `Clock`을 고정해 확인한다.
