# Spec: 글결 MCP OAuth — Claude 앱에 주소 하나로 붙이기 (023, v0.17.0)

> 020 글결 MCP의 다음 후보 "MCP OAuth(Claude 앱의 커스텀 커넥터)". 2026-10-20 사용자 "끝까지 다 해, 있는 힘껏" → 추천대로 정한 가안.
> 지금(020)은 마이페이지에서 열쇠를 만들어 복사해 붙인다. Claude 앱(웹·데스크톱·모바일)의 **커스텀 커넥터**는 열쇠 칸이 없고 OAuth로만 붙는다. 이제 주소(`https://<사이트>/api/v1/mcp`) 하나만 넣으면 글결 로그인·허락 화면이 뜨고, 허락하면 붙는다.
> 글결다운 모양: 허락 화면은 **위임장**. 원고지 칸에 "누가 / 무엇을 / 언제까지"가 적혀 있고, 허락하면 붉은 인장이 찍힌다.

## 사용자 이야기

### US1 커넥터로 붙이기 (P1)
1. 회원이 Claude 앱의 커스텀 커넥터에 글결 MCP 주소를 넣는다. Claude가 글결에 자기를 등록하고(동적 등록), 회원의 브라우저를 글결 **위임장** 화면으로 보낸다.
2. 로그인하지 않았으면 로그인 창을 먼저 띄우고, 로그인하면 위임장으로 돌아온다.
3. 위임장에는 앱 이름, 돌아갈 주소의 호스트, 할 수 있는 일(읽기만 / 읽기 + 초안 남기기, 회원이 고른다)이 보인다. **허락**하면 앱으로 돌아가고 앱이 글결 도구를 쓴다. **거절**하면 앱에 거절을 알린다.
4. 앱이 받은 출입증(접근 토큰)은 1시간, 새로 받는 표(갱신 토큰)는 30일. 앱은 갱신 토큰으로 새 출입증을 받는다(받을 때마다 갱신 토큰도 바뀐다).

**받아들이는 기준**
- S1-1 MCP 주소에 출입증 없이 오면 401과 `WWW-Authenticate: Bearer resource_metadata="<보호 자원 메타데이터 주소>"`. 메타데이터 두 개(보호 자원 RFC 9728, 인가 서버 RFC 8414)를 누구나 읽는다.
- S1-2 동적 등록(RFC 7591): 공개 클라이언트(`token_endpoint_auth_method: none`)만. 돌아갈 주소는 https 또는 `http://localhost`·`127.0.0.1`(포트 아무거나)만, 1~5개. 이름 1~100자(없으면 "이름 없는 앱").
- S1-3 인가 요청: `response_type=code`, PKCE `S256`만(없거나 plain이면 거절). 모르는 클라이언트·등록되지 않은 돌아갈 주소면 **돌려보내지 않고** 글결 오류 화면. 그 밖의 잘못은 돌아갈 주소로 `error=invalid_request` 등을 붙여 보낸다.
- S1-4 허락 코드는 한 번만, 5분. 다른 클라이언트·다른 돌아갈 주소·틀린 `code_verifier`면 `invalid_grant`. 같은 코드를 두 번 쓰면 그 코드로 만든 연결을 끊는다.
- S1-5 갱신 토큰은 쓸 때마다 바뀐다. 이미 바뀐(옛) 갱신 토큰이 다시 오면 그 연결을 통째로 끊는다(도난 감지).
- S1-6 `resource`(RFC 8707)를 보내면 글결 MCP 주소와 같아야 한다(다르면 `invalid_target`).
- S1-7 "읽기만"으로 허락한 연결은 초안 남기기 도구를 쓰지 못한다(020과 같은 오류).

### US2 연결된 앱 관리 (P1)
1. 마이페이지 "AI 비서 연결"에 **연결된 앱** 목록: 앱 이름, 할 수 있는 일, 허락한 날, 마지막 사용. **끊기**로 바로 끊는다(출입증·갱신 토큰 모두 못 쓴다).
2. "Claude 앱에 붙이기" 탭: 복사할 MCP 주소와 순서(설정 → 커넥터 → 커스텀 커넥터 추가 → 주소 붙이기 → 허락).
3. 비밀번호를 바꾸거나, 탈퇴하거나, 편집실이 정지하면 연결된 앱도 모두 끊긴다(020의 열쇠와 같다).

**받아들이는 기준**
- S2-1 남의 연결을 끊으려 하면 404. 끊은 연결의 출입증으로 MCP에 오면 401.
- S2-2 회원 한 명당 연결된 앱은 10개까지. 넘으면 가장 오래 쓰지 않은 연결을 끊고 새로 잇는다.
- S2-3 정지된 회원은 위임장을 허락할 수 없고(로그인 안 됨), 이미 받은 출입증도 401.

## 범위 밖
- 비공개(confidential) 클라이언트·client_secret, OpenID Connect(id_token), Client ID Metadata Document, 글결 쪽에서 앱 미리 등록.
