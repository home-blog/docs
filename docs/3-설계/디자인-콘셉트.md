# 디자인 콘셉트: 원고지 한 묶음

> 2026-10-13 사용자 결정 ("이 컨셉으로 가보자"). 코드 PR #60(v0.5.1 원고지 손길). 화면 토큰은 코드 저장소 `frontend/src/index.css` 한곳.

## 한 줄로

**글결은 여러 사람이 함께 쓰는 원고지 한 묶음이다.** 원고지를 받아(가입) 한 칸씩 채워 쓰고(글쓰기) 탈고하면(저장), 여러 사람의 원고가 한 묶음으로 모인다.

블로그에서 하는 일마다 원고 쓰는 사람의 말과 물건을 하나씩 짝지었다. 꾸밈을 얹는 것이 아니라 **숫자(매수)와 동작(가입·쓰기·읽기·저장)에 뜻을 붙인다.**

## 짝 지은 말과 물건

| 블로그에서 하는 일 | 원고지 세계 | 화면 |
|---|---|---|
| 서비스 전체 | 원고지 한 묶음: 제목·쓴 사람·분량 칸이 있는 첫 장 | 첫 화면 머리 "원고지 표지" |
| 가입 | 원고지 받기 | 첫 화면 칸 버튼 |
| 글쓰기 | 이어 쓰기 | 회원 첫 화면 칸 버튼 |
| 내 블로그 | 내 원고지: 이름을 칸에 적고 쓴 매수를 센다 | 블로그 머리 |
| 글 길이 | 원고지 몇 매 (200자 = 1매, 올림) | 글 카드, 글 끝, 블로그·첫 화면 분량 |
| 읽기 | 칸을 채워 가며 읽기 | 글 화면 맨 위 원고지 20칸 |
| 다 읽음 | 도장(낙관) | 글 끝 "글결 원고" 도장 |
| 올리기 / 고치기 | 탈고 / 퇴고 | 저장 알림 도장 |
| 눈에 띄는 곳 | 형광펜 | 구역 제목, 카드 제목 |
| 없는 쪽 | 교정부호 (빨간 펜으로 긋고 고쳐 씀) | 404, 없는 글·블로그 |
| 아직 글이 없음 | 빈 원고지와 깜박이는 커서 | 빈 목록 |
| 무엇을 쓸까 | 원고지에 한 자씩 적히는 인사 | 첫 화면 오른쪽 원고지 |

## 색과 움직임

- 바탕은 종이(`--paper`), 글자는 먹(`--ink`), 칸 선은 초록 원고지(`--grid`, `--grid-strong`), 버튼은 먹 초록(`--accent`).
- 포인트는 둘만 아껴 쓴다: **형광펜 노랑**(`--highlight`), **인주·교정펜 빨강**(`--seal`). 빨강은 도장과 교정부호에만.
- 움직임은 화면에 처음 들어올 때 **한 번만**(한 자씩 적힘, 도장 쿵, 형광펜 긋기, 숫자 세어 올림). "움직임 줄이기" 설정이면 모두 끄고 처음부터 그려진 모습으로 보인다.
- 다크 모드는 "밤에 펼친 원고지": 같은 토큰을 어두운 값으로 한 벌 더.

## 새 화면을 더할 때

1. 그 화면에서 하는 일을 위 표의 말로 부를 수 있는지 본다 (예: 공지사항 → "알림판에 붙인 원고", 임시 저장 → "초고").
2. 새 색을 만들지 않는다. 노랑·빨강 포인트는 한 화면에 한 군데씩만.
3. 움직임은 한 번, 짧게(0.3~0.7초). 반복하는 것은 커서 깜박임 하나뿐.
4. 원고지·도장 같은 꾸밈은 화면 읽기 도구가 읽지 않게 하고(`aria-hidden`), 같은 뜻의 글자를 따로 둔다.
